# UI Design Tokens — Initial Direction

These are directional tokens for design review, not final implementation values.

## Visual language

- Base: clean light surfaces with a deep ink/navy structural color.
- Accent: controlled violet for progress and primary emphasis, derived from the third reference.
- Semantic colors: separate success, warning, danger and offline/sync states; never communicate status by color alone.
- Shape: consistent soft cards and sheets, with a separate pill treatment only for compact status/filter controls.
- Typography: highly legible sans-serif with tabular figures for currency, percentages and counters.

## Layout rhythm

- 4pt base grid.
- 8pt spacing increments for controls and sections.
- 16–24pt screen gutters depending on device width.
- 48pt minimum primary touch target.

## Dashboard hierarchy

1. Daily net progress.
2. Current operating KPIs.
3. Weekly trend.
4. Recent activity.
5. Secondary configuration and history actions.
